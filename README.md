# Pura Vida 🌿

A Nostr social application focused on spreading positivity with simple "PV" replies.

## Features

- **Personalized Feed**: Shows only notes from people you follow
- **Simple Interaction**: Only allows logged-in users to reply with "PV" messages
- **Clean Design**: Modern, responsive interface with a green theme
- **Nostr Integration**: Built on the decentralized Nostr protocol using NIP-01 and NIP-02
- **Real-time Updates**: Live updates of notes from your following list
- **Theme Support**: Light and dark mode support

## How It Works

1. **Connect**: Log in with your Nostr account using any NIP-07 compatible extension
2. **Follow People**: Use other Nostr clients to build your following list (kind 3 contact list)
3. **Browse**: View the latest notes from people you follow
4. **Spread Positivity**: Click the "PV" button on any note to reply with a positive message
5. **Good Vibes**: Help create a more positive social media experience within your network

## Technology Stack

- **React 18** with TypeScript
- **TailwindCSS** for styling with a custom green theme
- **Nostrify** for Nostr protocol integration
- **shadcn/ui** components for modern UI
- **Vite** for fast development and building
- **Inter Variable** font for clean typography

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```

## About "Pura Vida"

"Pura Vida" is a Costa Rican phrase meaning "pure life" - it represents a philosophy of living life to the fullest and maintaining a positive outlook. This application embodies that spirit by encouraging positive interactions on the Nostr network.
